# Vibraport

**Vibration Data Analysis and Reporting Tool for Blasting and Ground Vibration Monitoring**

Vibraport is a Python/Streamlit application for importing, analyzing, visualizing, and reporting vibration monitoring data recorded by **Vibracord seismographs**.

It is designed primarily for engineers and practitioners working with **blasting vibration, ground vibration monitoring, and waveform analysis**.

The application supports Vibracord `.sis` recordings as well as compatible CSV data and provides tools for waveform visualization, signal analysis, PPV analysis, attenuation regression, Signature Hole Analysis, long-term monitoring, and reporting.

> **Status:** Active development  
> **Application type:** Local/web-based Streamlit application  
> **Primary language:** Python

The application is intended to help users inspect the characteristics of a measured vibration event rather than relying only on a single PPV value.

### Signature Hole Analysis

Vibraport includes a Signature Hole Analysis workflow for investigating the potential interaction of multiple blast-induced vibration waveforms.

A recorded signature waveform can be used to simulate a larger blast pattern by:

1. Taking a measured signature-hole waveform.
2. Assigning firing delays to individual holes.
3. Shifting copies of the waveform in time.
4. Applying optional amplitude scaling.
5. Superimposing the resulting waveforms.
6. Evaluating the resulting combined vibration.

The underlying implementation performs **zero-padded waveform superposition**, avoiding circular wrap-around artifacts.

The application can also apply an optional **USBM scaled-distance amplitude correction** based on charge weight and distance ratios.

#### Important modeling limitation

The USBM scaling implementation changes waveform amplitude but assumes that the scaled waveform retains the same basic shape and frequency content as the measured signature waveform.

This is an engineering approximation. It does not explicitly model:

- Frequency-dependent attenuation
- Changes in waveform duration
- Changes in frequency content with propagation distance
- Different geological propagation paths
- Complex blast-wave interactions

Therefore, Signature Hole Analysis should be treated as a **simulation/engineering analysis tool**, not as an exact physical prediction of a blast event.

### Attenuation & Safe Zone Analysis

Vibraport can analyze multiple blast monitoring events and perform PPV attenuation analysis using scaled distance.

The analysis can be used to investigate relationships between:

- PPV
- Distance
- Maximum charge weight
- Scaled distance

The results can then be used to estimate parameters such as:

- Expected PPV
- Safe distance
- Maximum allowable charge
- Attenuation behavior

The application also provides SNI 7571:2023-related building-class comparison tables.

The regression functionality is separated into the `regression/` package, including scaled-distance and fitting modules.

---

### Bargraph Monitoring

Vibraport supports long-term **Bargraph recordings**, including Vibracord files using the `M` recording format.

The monitoring interface provides:

- Amplitude visualization
- Frequency information
- Configurable alert thresholds
- Exceedance markers
- Frequency distribution
- Long-term recording inspection

Bargraph files are handled separately from normal waveform recordings because they contain interval-based measurements rather than full velocity/acceleration/displacement waveforms.

---

### Report Generation

The application includes a reporting module for generating formatted reports from vibration recordings.

The report workflow is designed to consolidate relevant measurement information and analysis results into a printable/report-ready format.

## Core Processing Modules

### `core/waveform.py`

Handles waveform and file processing, including parsing and preparation of vibration data.

### `core/fft_analysis.py`

Contains frequency-domain/signal analysis functionality used by the application.

### `core/superposition.py`

Implements time-domain superposition of multiple copies of a signature waveform.

```text
Signature waveform
        │
        ├── Delay 1 ──┐
        ├── Delay 2 ──┤
        ├── Delay 3 ──┤
        └── Delay N ──┤
                      ↓
                Superposition
                      ↓
             Combined waveform
```

The implementation uses sample-based time shifts and optional amplitude scaling.

### `core/scaling.py`

Implements USBM-style charge-weight/distance amplitude scaling for Signature Hole Analysis.

The current implementation is based on:

```text
PPV = K × (D / √W)^(-B)
```

and derives a relative waveform amplitude scale factor from charge-weight ratio, distance ratio, and the attenuation exponent.

### `core/delay.py`

Handles firing-delay calculations used by Signature Hole Analysis.

### `core/metrics.py`

Contains vibration measurement/analysis metrics.

### `core/sni_chart.py`

Provides charting functionality associated with SNI 7571:2023 compliance visualization.

### 2. Create a virtual environment

Linux/macOS:


Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

```bash

```

### 4. Start Vibraport

```bash
streamlit run app.py
```

Streamlit will display the local application URL in the terminal, normally:

```text
http://localhost:8501
```

## Basic Workflow

1. Start Vibraport.
2. Upload one or more Vibracord `.sis` or CSV files.
3. Select the active recording.
4. Choose an analysis module from the sidebar.
5. Inspect the waveform and measurement data.
6. Perform the required engineering analysis.
7. Generate a report when required.

For attenuation analysis, multiple uploaded recordings can be used as the dataset for PPV/scaled-distance analysis.

## Limitations

Vibraport does not replace:

- A calibrated vibration monitoring instrument
- Proper field measurement procedures
- Site-specific vibration studies
- Engineering judgement
- Applicable regulations or standards

In particular, numerical simulations based on a single signature waveform necessarily make simplifying assumptions about how blast vibration propagates and changes between holes.

The Signature Hole scaling implementation explicitly does not model frequency-dependent attenuation or changes in waveform shape caused by different propagation distances or charge configurations.
